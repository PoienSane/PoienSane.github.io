# 墨序 Moxu

**把题解、代码和思路放在同一个工作台。**

墨序是一款运行在浏览器中的算法学习与写作工具。你可以用 Markdown 整理题解，在 C++ 工作台编写代码、管理样例和进行对拍，也可以通过函数画板、几何工具和文件比较辅助分析。

## 功能一览

### 题解写作

- 使用 Markdown 编辑文档，预览排版、代码和数学公式。
- 管理多个文档，并通过版本快照回看具体文件的修改。
- 使用命令面板、工具箱、主题和字号设置，调整工作方式。

### C++ 工作台

新建或打开 `.cpp` 文件，即可在墨序中切换到代码工作台。

- 编写 C++ 代码，使用语法高亮、补全、快捷键和诊断信息。按 `Ctrl+F`（macOS 为 `⌘F`）打开中文查找与替换面板，支持匹配计数、正则表达式、大小写和全词匹配；点击「展开替换」或在编辑器内按 `Ctrl+H` 可打开替换操作。
- 管理测试点，运行代码，查看输出、错误和与期望结果的比较。
- 导入题面和样例，使用 OI 模板与常用工具。
- 通过统一对拍工作台比较程序，记录种子和反例，并将数据回填到测试点。
- 使用 SPJ 检查非唯一答案。内置官方 testlib 头文件，提供整数、浮点序列、Yes/No、Case 格式和部分分等示例；支持常用的 `inf`、`ouf`、`ans` 读取接口以及 `quitf`、`quitp`、`quitpi` 和 `_pc` 结果。SPJ 工作台支持展开编辑、常用代码片段、判题器导入与下载，并可分别输入 `inf`、`ouf` 和 `ans` 独立测试 checker。使用洛谷文档所列的 testlib 0.9.45；墨序的编译设置与运行环境可能与洛谷不同。

C++ 运行、评测和对拍依赖在线编译服务；运行环境与实际 OJ 不完全相同，样例通过不代表提交一定通过。testlib 的常用 checker 场景已支持，但不保证覆盖全部功能或所有平台差异，交互题暂不支持。

### FC 文件比较

FC 支持直接输入文本或选择 `.in`、`.out`、`.ans`、`.txt` 等文件，在浏览器本地分块比较，不上传文件内容。

- **逐字节比较**：检查空格、换行等精确差异，定位第一个不同的字节。
- **忽略空白比较**：按 UTF-8 token 比较，定位第一个不同的 token。
- 支持拖入文件、交换两侧、停止比较和下载比较报告。大文件内容不会被渲染到文本框中。

FC 已实测比较 100 MiB 文件。token 模式要求文件为有效 UTF-8，单个 token 上限为 4 MiB。

### 绘图与辅助工具

- **2D 函数与几何**：绘制函数、进行几何构造并选择重合点。
- **3D 曲面**：调整网格、颜色、投影和旋转中心，观察曲面形态。
- **辅助工具**：通过工具箱使用代码查重、复杂度分析等工具。工作台也提供可配置的写作与代码助手。

## 快速开始

### 直接打开

下载 [`moxu-standalone.html`](moxu-standalone.html)，使用现代浏览器打开。文档编辑和部分本地工具可离线使用；在线编译、评测、对拍及其他联网功能需要网络。

1. 新建 Markdown 文档，开始编写题解。
2. 新建 C++ 文件，进入代码工作台，在「测试」中添加输入和期望输出。
3. 点击运行或评测，查看结果；需要比较文件时，打开侧栏的「FC 文件比较」。

单文件页面是构建时的快照，修改源码后需要重新构建才能更新。直接打开的本地文件地址不能用于跨设备分享；如需分享，请部署网站或导出数据。

### 从源码运行

建议使用 **Node.js 22 LTS**。在项目根目录执行：

```bash
npm ci
npm run dev
```

在浏览器中打开终端显示的地址。其他常用命令：

```bash
npm run typecheck  # 类型检查
npm test           # 自动化测试；部分测试需要 g++
npm run build      # 构建到 dist/index.html
```

C++ 工作台源码位于 `cpp-source/`。修改后，先重新生成嵌入资源，再构建主应用：

```bash
npm ci --prefix cpp-source
npm run build:cpp
npm run build
cp dist/index.html moxu-standalone.html
```

Windows 用户可使用文件管理器复制构建结果，或运行 `copy dist\index.html moxu-standalone.html`。若提交 C++ 工作台改动，也应提交更新后的 `src/cpp-workbench/embedded.html`。

## 本地大文件评测（Linux 命令行）

源码包提供 `scripts/local-judge.py`，使用本机 Python 3 和 g++，通过文件输入输出运行 C++，不将大数据嵌入源码或发送到 Wandbox。输入、参考答案和输出各支持最多 100 MiB；输出直接写入新文件，不会覆盖已有文件。

```bash
python3 scripts/local-judge.py --source main.cpp --input data.in --answer data.ans --output result.out --time 30 --memory 512
```

可选 `--spj checker.cpp` 使用随项目附带的 testlib 0.9.45；不提供参考答案时仅运行、不判定 AC。默认比较为逐字节比较；运行结果以 JSON 显示。可用 `python3 test/local-judge.test.py` 验证本机路径（测试会临时读写 100 MiB 文件）。

**安全提示：本地评测器不是安全沙箱，只能运行可信的程序和判题器。** 程序可能访问或修改本机文件及网络；资源限制不等于安全隔离。当前工具仅支持 Linux，未接入网页、在线服务或对拍功能；网页的 Wandbox 大数据和输出限制仍然存在。

## 部署到 GitHub Pages

1. 将项目内容上传到 GitHub 仓库根目录，保留 `.github/` 等隐藏文件；无需上传 `node_modules/` 和 `dist/`。
2. 在仓库的 **Settings → Pages** 中，将部署来源设为 **GitHub Actions**。
3. 推送到 `main` 分支，或在 Actions 中手动运行 **Deploy to GitHub Pages**。
4. 构建与部署成功后，访问 Pages 提供的地址。

工作流会安装依赖、检查类型、运行测试并构建主应用。它使用仓库中已有的 C++ 嵌入资源，不会自动重新构建 `cpp-source/`；修改子工作台后请先在本地执行 `npm run build:cpp` 并提交生成的资源。

## 数据、隐私与使用限制

- **本地保存**：文档和工作区数据主要保存在当前浏览器中，并非自动云同步。清理浏览器数据、使用无痕模式或更换设备可能导致数据丢失，请定期导出备份。
- **联网内容**：在线 C++ 运行、评测和对拍会向 Wandbox 发送代码与测试数据；其他联网服务也可能接收你提交的内容。请勿提交敏感信息，并注意第三方服务的可用性。
- **大文件**：C++ 测试面板可选择单个不超过 100 MiB 的文件；超过 2 MiB 的文件不会渲染，也不能用于当前在线运行或评测。刷新后需重新选择。在线评测单个输入或答案上限为 2 MiB，所有测试数据合计上限为 4 MiB；服务自身可能有更低限制。
- **输出**：在线结果最多接收 1 MiB。超出时会标记为截断，下载的也只是已接收部分，不能当作完整输出。
- **备份**：C++ 工作台支持 JSON 导入与导出；代码快照不等于完整工作区备份。分享备份前，请检查其中是否包含敏感内容。

### FC 自定义比较语言

在 FC 文件比较中启用「自定义比较函数」，即可编辑 `compare.mx`。这是受限的声明式规则，不执行 JavaScript，也不能访问文件或网络：

```text
compare(left, right) {
  tokens;                // 必填：按 UTF-8 空白分隔的 token 逐项比较
  ignore_case;           // 可选：文本忽略大小写
  numeric(0.01, 0.000001); // 可选：绝对误差、相对误差，满足任一即可
}
```

规则可以删去可选项，以分号结尾；`//` 开始单行注释。非数值 token 按文本比较，token 数量必须相同。数值采用双精度浮点；绝对值超过安全整数上限、非有限或下溢为零的数值回退到文本比较。单个 token 最大 4 MiB。大文件比较在本机分块进行，不等同于在线评测支持大文件。
