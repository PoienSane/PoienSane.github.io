墨序：无需在自己的电脑安装 npm / Node.js

推荐方式：GitHub Pages 自动构建并发布

1. 在 GitHub 新建一个仓库（Repository）。
2. 把本文件夹里的所有文件和文件夹上传到仓库根目录。
   注意：要上传 .github 文件夹；如果网页隐藏了它，请用 GitHub 的 Upload files 或 Git 客户端确保它被上传。
3. 等待仓库的 Actions 页面里「Build and deploy 墨序」运行成功。
4. 打开仓库 Settings -> Pages，将 Build and deployment 的 Source 设为「GitHub Actions」。
5. Actions 部署完成后，Pages 页面会显示网站地址。以后每次更新代码，GitHub 会自动重新构建并发布。

你只需要浏览器和 GitHub 账号；npm / Node.js 只在 GitHub 的云端构建机上运行，不需要安装到自己的电脑。

AI 与编译功能
- AI 默认尝试使用免注册、免 API Key 的公开免费模型通道。免费模型的额度、可用性、跨域策略由服务提供方决定，可能临时限流或下线。
- 编译运行使用在线编译服务，需要联网。代码会发送给第三方编译服务执行；不要提交密码、令牌或其他秘密。
- AI 分析会把你选择的代码、输入、输出和日志发送给当前 AI 服务商。使用前请确认内容可以外发。

如果部署失败：打开仓库 Actions，点失败的工作流查看日志。不要在本地安装 npm 来排错；把错误日志发给 AI 即可继续定位。
